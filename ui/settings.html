API 管理

默认翻译源

多引擎对比翻译时同时显示这些服务的译文，最多 3 个

API Key 保存在系统安全存储（Windows 凭据管理器 / macOS 钥匙串），不会写入配置文件或日志。翻译内容只发送到你启用的翻译服务（当前服务，以及开启后的故障切换和对比服务）。

关于

TopBar Translate

鼠标触顶即可翻译的轻量桌面工具。默认使用 Bilibili 开源的 Index-Translate 免费公网 API，无需注册或 API Key。

免费公网 API 的限流、稳定性及商业使用条件以官方政策为准，不保证无限调用。
