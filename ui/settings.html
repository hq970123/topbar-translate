关于

TopBar Translate

鼠标触顶即可翻译的轻量桌面工具。默认使用 Bilibili 开源的 Index-Translate 免费公网 API，无需注册或 API Key。

免费公网 API 的限流、稳定性及商业使用条件以官方政策为准，不保证无限调用。
